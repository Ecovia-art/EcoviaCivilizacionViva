# Guía Paso a Paso: El "Cerebro" de Ecovia (index.html)

El archivo `index.html` es el corazón de tu proyecto. Cuando lo subas a GitHub, este archivo le dirá al navegador qué mostrar primero. He revisado la estructura basada en tus diseños de alta fidelidad:

## 1. Lo que contiene tu index.html
- **Estructura Base**: Define que es un documento HTML5 moderno.
- **Vínculos Estéticos**: Conecta con los archivos CSS que contienen la estética "Architectural Harmony" (tus colores esmeralda y oro).
- **El Contenedor del Núcleo**: Un espacio dedicado para que el motor de Bio-Resonancia (JavaScript) se renderice.
- **Navegación**: Los enlaces a las otras secciones que hemos diseñado (Mapa Energético, Perfil de Gobernador, etc.).

## 2. Verificación previa a la subida
Antes de arrastrarlo a GitHub, asegúrate de que en tu carpeta local:
1. El archivo se llame exactamente `index.html` (todo en minúsculas).
2. Esté en la **raíz** de la carpeta (no dentro de otra carpeta llamada "html" o "v1").
3. Las carpetas `css`, `js` e `img` estén al mismo nivel que el `index.html`.

## 3. ¿Cómo leer el código?
Si abres el archivo con un bloc de notas, busca estas líneas clave:
- `<title>Ecovia: Civilización Viva</title>`: Es el nombre que aparecerá en la pestaña del navegador.
- `<link rel="stylesheet" href="css/style.css">`: Es el cable que conecta el diseño.
- `<script src="js/main.js"></script>`: Es el motor que dará vida a las animaciones.
